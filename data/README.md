# Data

This directory holds JSON and CSV data pulled from live sources. Files are auto-generated by slash commands — don't edit manually unless you know what you're doing.

Key files:
- `live-snapshot.json` — Main dashboard data (team hours, pipeline, 1:1 dates)
- `forecast-health.json` — AE forecast sheet health (optional)
- `panels.json` — Deals closing, wins, action items

These are populated by `/pull-all` and updated by individual pull commands.
